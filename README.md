## 我的项目

### MIC_FFT
基于 STM32F103C8T6 的麦克风音频 FFT 分析：ADC 采集 + ARM DSP 库做 256 点 FFT，OLED 实时显示时域波形与频域频谱。
https://github.com/tyuecode/MIC_FFT

### simple-chat-server
C 语言聊天室，服务端使用 epoll + 非阻塞 I/O 实现高并发，支持群聊与私聊。
https://github.com/tyuecode/simple-chat-server
